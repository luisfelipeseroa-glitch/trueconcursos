# EstudaFarma V5 — SES-RJ / IBDO

Versão 5 do app de estudos para Farmacêutico SES-RJ/IASERJ.

Principais novidades:
- banco com mais de 150 questões inéditas em estilo IBDO;
- filtros por matéria, assunto, dificuldade, erros e favoritas;
- simulado livre ou modo SES-RJ completo;
- cronômetro com pausa;
- histórico de simulados e desempenho por disciplina;
- projeção de desempenho;
- caderno de erros, flashcards e estudo adaptativo;
- persistência local no navegador;
- configurado para GitHub Pages em /trueconcursos/.

Ao publicar, preserve seu .github/workflows/deploy.yml já funcional.
