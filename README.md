# EstudaFarma
Protótipo independente do aplicativo de estudos para concurso de Farmacêutico.

## Executar
1. Instale Node.js.
2. Abra esta pasta no terminal.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço mostrado pelo Vite.

## Estrutura inicial
- Dashboard responsivo
- Português
- Políticas Públicas de Saúde / SUS
- Conhecimentos Específicos — Farmácia
- Questões
- Simulados
- Flashcards
- Caderno de erros
- Biblioteca
- Desempenho

Os dados atuais são demonstrativos. Próxima etapa: persistência local/banco de dados, árvore completa do edital, motor de questões e algoritmo de domínio/revisão espaçada.
