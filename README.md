# EstudaFarma — True Concursos

Aplicativo de estudos para concurso de Farmacêutico.

## Publicar no GitHub Pages
Este projeto já está configurado para o repositório `trueconcursos`.

1. Envie **o conteúdo desta pasta** para a raiz do repositório (não envie a pasta externa inteira).
2. No GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Abra a aba **Actions** e aguarde o workflow `Deploy EstudaFarma to GitHub Pages` ficar verde.
4. Acesse: `https://luisfelipeseroa-glitch.github.io/trueconcursos/`

## Rodar no computador
```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
```
